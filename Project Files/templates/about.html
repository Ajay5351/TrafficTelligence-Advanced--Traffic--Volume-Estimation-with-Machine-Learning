About This Project

🚦 Traffic Intelligence is a machine learning project designed to estimate traffic volume based on environmental and time-based factors. It uses a Random Forest Regressor trained on real traffic datasets.

The system can be extended with more features such as holidays, weather conditions, and location-based traffic history for improved accuracy.
